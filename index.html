1. Control de Versiones

Definición

Sistema que guarda los cambios del código a lo largo del tiempo. Permite regresar a una versión anterior, ver quién cambió qué y trabajar en equipo sin borrar el trabajo de otros.

¿Cuáles son?

Local: Solo en tu compu. Ej: RCS.

Centralizado: Un solo servidor. Ej: SVN, CVS.

Distribuido: Cada quien tiene copia completa. Ej: Git, Mercurial.

Características, ventajas y desventajas

Git: Distribuido, rápido, con ramas. Ventaja: muy usado. Desventaja: al inicio es difícil.

GitHub / GitLab: Guardan tu Git en la nube. Ventaja: respaldo. Desventaja: necesitas internet.

SVN: Centralizado, fácil. Ventaja: simple. Desventaja: si falla el servidor, nadie trabaja.

¿Cómo funciona?

1. Cambias algo. 2. git add 3. git commit -m "mensaje" 4. git push.

Rastreo y gestión de cambios

Con el historial ves qué, cuándo y quién cambió. Si algo se rompe, regresas al commit anterior.

2. Persistencia y Acceso a Datos

Definición

Que los datos no se borren cuando se cierra la app. Ej: que tus notas sigan ahí al volver a abrirla.

Formas de persistencia

Archivos: Fotos, texto, PDF en la memoria.

Base de datos local: Datos ordenados sin internet. Ej: SQLite, Room.

Base de datos remota por servicios web: Datos en un servidor. Ej: Firebase, MySQL.

Tipos de datos

En archivos: imágenes, audios. En local: texto, números, fechas. En remota: usuarios, pedidos, mensajes.

Control de acceso

Biblioteca de clases: Códigos ya hechos. Clases de SQLite: SQLiteOpenHelper y SQLiteDatabase. ORM: Usas objetos en vez de SQL. Ej: Room.

Autenticación y servicios web

1. Pones correo y contraseña. 2. El servidor te da un token. 3. La app pide datos con GET y POST.

3. Gestión de Sensores

Definición

Componentes que detectan lo real: movimiento, luz, ubicación, y lo convierten en datos para la app.

Tipos

Movimiento: Acelerómetro, giroscopio. Posición: GPS, brújula. Ambiente: Luz, proximidad. Biométricos: Huella, cara.

Proceso

1. Habilitación: Se pide permiso. 2. Obtención: Se lee el dato. 3. Procesamiento: Se interpreta. Ej: contar pasos.

4. Uso de Recursos Multimedia

Definición

Lo que hace que la app se vea y se escuche bien: imágenes, sonidos, videos y animaciones.

Tipos

Imágenes: JPG, PNG. Audio: Música, efectos. Video: Tutoriales. Animaciones: Botones que se mueven, GIF.

Dónde se guardan

En Android: res/drawable para imágenes, res/raw para audio/video, assets para archivos. En Flutter: assets/.

Componentes

ImageView, MediaPlayer / ExoPlayer, Glide, Lottie.

5. Servicios y Notificaciones

Definición

Servicio: proceso que sigue aunque no tengas la app abierta. Notificación: aviso que te llega.

Tareas en segundo plano

Trabajos que siguen con la app cerrada. Ej: descargar archivo, reproducir música.

Implementación

Proveedor de contenido: Comparte datos entre apps, ej: contactos. Segundo plano: WorkManager. Notificación: NotificationManager. Nube: Firebase Cloud Messaging.

Nube

Firebase, AWS Amplify, Google Cloud, Azure.

6. Librerías y Toolkits

¿Qué es librería y toolkit?

Librería: Funciones ya hechas que tú usas cuando quieres. Tú mandas.

Toolkit: Paquete completo con herramientas y reglas. El toolkit te dice cómo trabajar.

Librerías especializadas

Retrofit para internet, Glide para imágenes, Room para base de datos, Google Maps para mapas, Lottie para animaciones.

Toolkits

Android SDK: Solo Android. iOS SDK: Solo iPhone. Flutter: Una app para los dos, con Dart. React Native: Una app para los dos, con JavaScript.

7. Depuración y Seguridad

¿Qué es?

Depuración: Buscar y corregir errores. Seguridad: Proteger datos del usuario.

Herramientas

Logcat, Breakpoints, Emulador, Profiler, Crashlytics.

Seguridad

No guardar contraseñas en texto, usar HTTPS, pedir solo permisos necesarios, usar token y cifrar datos.
